# 智慧水利数字孪生平台

数字孪生智慧水利一体化平台演示版（纯前端 HTML + JavaScript + ECharts，无后端依赖）。

## 功能模块（8 大模块 · 21 个页面）

- **数字孪生可视化底座**：一张图（SVG 流域地图 + 图层树 + 测点详情 + 场景漫游 + 专题图叠加）
- **物联感知监测**：监测数据总览、时序曲线分析、视频监控（GB/T28181 演示）、设备台账
- **水利专业模型与仿真预演**：模型方案管理、洪水演进动画、双方案指标对比
- **业务应用**：防汛（汛情监视/预警/险情/会商）、水资源（取水许可/取用水监测）、供水（工程台账/水质监测）、灌区（渠系台账/配水计划）
- **工程运维**：工程台账、巡检工单、缺陷维修养护
- **移动端适配**：抽屉式导航、底部弹出面板、单列布局
- **报表与系统**：领导驾驶舱大屏、自定义报表、对外 API、用户角色、操作日志

## 部署

推送 `website/**` 变更后 GitHub Actions 自动部署（见 `.github/workflows/deploy-pages.yml`）。
首次启用：仓库 Settings > Pages > Source 选 **GitHub Actions**。

## 技术栈

- 原生 JavaScript（无框架）、ECharts 5（CDN）、SVG
- 响应式适配：≤900px 抽屉导航 + 降列栅格；PC 端 ≥1920×1080 设计
